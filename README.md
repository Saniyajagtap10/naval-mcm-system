# ⚓ Naval Subsea Acoustic & MCM (Mine Countermeasures) System

An advanced tactical command system powered by Streamlit, PyTorch CNN models, and interactive GIS mapping for autonomous underwater vehicle (AUV) operations, subsea acoustic analysis, and maritime hazard detection.

## 🚀 Key Features
- **Real-Time AUV GIS Trajectory & Telemetry:** Live tracking with battery monitoring and depth profiles.
- **AI-Powered Threat Detection:** PyTorch CNN integration for classifying seabed hazards and mine ordnance.
- **Dynamic Acoustic Frequency Spectrum:** Real-time FFT visualization based on target sonar scans.
- **3D Bathymetry Terrain:** Interactive ocean floor topography and obstacle mapping.
- **Tactical Controls:** Emergency Return-to-Home (RTH) and comprehensive mission audit logging.

## 🛠️ Tech Stack
- **Frontend/UI:** Streamlit (Custom Dark Tactical Theme)
- **AI & Deep Learning:** PyTorch, TorchVision
- **Geospatial & Visualization:** Folium, Plotly, OpenCV, NumPy, Pandas
